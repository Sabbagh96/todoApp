# Todo App

A modern Todo application built with React.js for managing daily tasks in a clean and organized way.  
The project was created to practice React fundamentals, state management, routing, and building reusable components.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Filter tasks by status
- Theme switching support
- Authentication state management
- Global state management
- Reusable React components
- Clean and organized folder structure

## Technologies Used

- React.js
- JavaScript
- Redux / Redux Toolkit
- React Redux
- React Router
- Context API
- React Hooks
- CSS
- Vite

## Concepts Practiced

- Component-based architecture
- State management using Redux
- Global app state using Context API
- Routing between pages
- Props and component communication
- Conditional rendering
- Event handling
- Form handling
- Clean code structure

## Project Purpose

This project was built as a learning project to practice building real-world React applications.  
It focuses on managing application state, organizing components, handling user interactions, and applying modern React development patterns.
